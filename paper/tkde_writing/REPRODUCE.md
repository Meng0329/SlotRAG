# TKDE Paper Reproduction

This note documents how to reproduce every numeric claim in the TKDE
submission (`main.pdf`) from raw run artifacts. All numbers are derived by
script from the stored `runs/` JSON; no figure/table value is hand-typed.

## 1. Build the paper

```bash
cd paper/tkde_writing
pdflatex -interaction=nonstopmode main.tex   # pass 1
bibtex main                                   # references
pdflatex -interaction=nonstopmode main.tex   # pass 2
pdflatex -interaction=nonstopmode main.tex   # pass 3 (resolve cross-refs)
```

Expected: `main.pdf`, 12 pages, 0 undefined citations, 0 unresolved
references. The only BibTeX warnings are "empty publisher/address" for the
three 2026 arXiv preprints whose venue is genuinely unpublished.

## 2. Reproduce the main table and all statistics

```bash
cd paper/tkde_writing
python3 audit_numbers.py
```

This re-derives, from raw per-question records:

- **RQ1–RQ3 matched-budget table** (Table 1): pooled n / EM / Δcalls, per-dataset
  EM with half-up rounding, pooled EM bootstrap CI (seed 2027, 200k iterations),
  McNemar discordant pairs, per-dataset cost bootstrap p + Holm adjustment,
  the 6/55 asymmetric-call disclosure, the ≥3-slot benefit-domain cost/EM,
  the §9 overhead table, and the compiled slot-count strata.
- **RQ6 external baselines** (§8 paragraph): native-budget exact-match for
  IRCoT / ReAct / Hybrid RAG / static / chain on the 20/20/24-question external
  samples (`tkde-r11-ext-baselines-q38`). All 15 EM values are compared against
  the paper text and flagged `[OK]` / `MISMATCH`.

Runtime: ~5 minutes (dominated by the 200k-iteration paired bootstrap).
Every printed line ends with `[OK]` when the paper matches the artifacts.

was never persisted in a sealed artifact (honestly disclosed in §8 RQ2).

## 4. Provenance / frozen state

- Generator: **qwen3.8-27b** (Agnes endpoint). Subject to provider
  non-determinism; the audit uses the realized artifacts, not a fresh run.
- Development/validation split, seed = 2027, 30/30/40 stratified sampling
  (per `configs/experiments/*.yaml`).
- **SEALED_TEST** (held-out 40%) is pre-registered but not yet executed; all
  reported numbers are development/validation. This boundary is disclosed in
  §Limitations.
- External-baseline (R11) samples are small and not the pre-registered sealed
  set; they are reported as corroborating evidence, not a primary result.

## 5. Honesty boundaries (what is NOT claimed)

- No EM win on any dataset (McNemar p ≥ 0.625; pooled CI includes 0).
- No statistically-supported cost reduction on the full sample (p ∈ [0.119,
  0.581]); only the exploratory ≥3-slot subdomain shows p = 0.036 (exactly
  zero EM difference).
- No runtime re-optimization contribution (G4 falsified → future work).
- No universal accuracy claim over upstream baselines; only a clean MuSiQue win
  on the external samples.
