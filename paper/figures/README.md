# Figures — Source and Reproduction

All four publication figures are generated by a single Python script. No
figure is hand-drawn or editor-only; every value is either schematic
(system overview, motivating example) or transcribed from frozen result
artifacts in `research/hstruct_validation_census/`.

## Figure 1 — System Overview (`system_overview.pdf`)

- **script**: `paper/figures/gen_all_figs.py` → `fig1_system_overview()`
- **input**: none (schematic; system architecture)
- **output**: `paper/figures/system_overview.pdf`

## Figure 2 — Budget Mismatch + Confusion Matrix (`budget_mismatch.pdf`)

- **script**: `paper/figures/gen_all_figs.py` → `fig2_budget_mismatch()`
- **input**: embedded frozen values from
  `research/hstruct_validation_census/validation_structural_census.csv`
  (confusion matrix: TN=76, FP=128, FN=0, TP=146; 4+4+4 > B=8 schematic)
- **output**: `paper/figures/budget_mismatch.pdf`

## Figure 3 — Structural Regime Effect (`regime_effect.pdf`)

- **script**: `paper/figures/gen_all_figs.py` → `fig3_regime_effect()`
- **input**: embedded frozen values from
  `research/hstruct_validation_census/hstruct2_flat_results.csv` (deep:
  +0.0771, n=350) and `hstruct3_gate_test.csv` (shallow: −0.021, n=8,085)
- **output**: `paper/figures/regime_effect.pdf`

## Figure 4 — Three-Arm Ablation (`three_arm_ablation.pdf`)

- **script**: `paper/figures/gen_all_figs.py` → `fig4_three_arm()`
- **input**: embedded frozen values from
  `research/hstruct_validation_census/hstruct2_three_arm_comparison.csv`
  (static 0.1714, flat 0.2486, chain 0.2571; BE 146→0)
- **output**: `paper/figures/three_arm_ablation.pdf`

## Reproduction

```bash
cd paper/figures
python3 gen_all_figs.py
```

Regenerates all four `*.pdf` (vector) and `*.png` (preview) files.

## Notes

- PDF is the canonical vector source for submission. PNGs are preview-only
  and must NOT be used as the formal vector source.
- Fonts: DejaVu Serif (matplotlib default); embedded at compile time.
- `coverage_main.png` is a legacy artifact from the superseded chain-law
  draft; not used in the current paper.
